🔍 How This Application Works

DATA LAYER:

• Array todos = [] stores all tasks

• Each todo is an object: {id, text, completed}

FUNCTIONS LAYER:

• addTodo() - Creates new tasks

• toggleTodo() - Marks tasks complete/incomplete

• deleteTodo() - Removes tasks

• renderTodos() - Updates the display

UI LAYER:

• HTML elements show the data

• User interactions trigger functions

• Functions modify data

• UI automatically updates to reflect changes

DATA FLOW:

User Action → Function Call → Data Change → UI Update

This is the foundation of ALL modern web apps!
